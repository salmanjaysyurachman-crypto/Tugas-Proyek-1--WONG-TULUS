📄 Deskripsi
Sistem ini merupakan aplikasi berbasis Python yang dirancang untuk membantu pengelolaan perpustakaan sekolah.  
Aplikasi ini bertujuan untuk mempermudah pendataan buku, proses peminjaman dan pengembalian, serta pencatatan transaksi perpustakaan secara terstruktur dan terdokumentasi.
